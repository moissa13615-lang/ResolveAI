# ResolveAI

An AI-powered IT Help Desk and Automation Platform built using Microsoft Azure.

## Project Overview

ResolveAI is an enterprise-style IT support application designed to
streamline ticket management, provide AI-assisted troubleshooting,
and automate common IT support workflows.

## Planned Features

- Employee and technician dashboards
- IT support ticket management
- AI-powered ticket classification
- AI-assisted troubleshooting
- Automated IT support workflows
- Microsoft Entra ID authentication
- Analytics and reporting
- Microsoft Azure cloud deployment

## Technology Stack

- Frontend: React + TypeScript
- Backend: Python + FastAPI
- Cloud: Microsoft Azure
- Database: SQLite (development)
- AI: Azure AI services (planned)
